# Windows Junk Cleaner

A simple `.bat` script for cleaning unnecessary temporary files on Windows.

## Features

* Cleans `%TEMP%`
* Cleans `C:\Windows\Temp`
* Cleans Windows Update cache
* Cleans DirectX Shader Cache
* Skips files currently in use
* No installation required

## Usage

1. Download `cleaner.bat`
2. Right-click the file
3. Select **Run as administrator**
4. Wait for the cleanup to finish

## Requirements

* Windows 10 / 11
* No additional software required

## Safety

The script only targets temporary and cache directories.

It does **not** delete files from:

* Desktop
* Documents
* Downloads
* Pictures
* Videos
* Music

Always review `.bat` scripts before running them as administrator.
